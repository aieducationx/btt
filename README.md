# Bilim, Teknoloji ve Toplum — Mikroöğretim

Anadolu Üniversitesi Eğitim Fakültesi, Sosyal Bilgiler Öğretmenliği Programı için
hazırlanmış açık eğitim kaynağı. On dört ders, sekiz Avrupa Birliği modülü (AI-CompEU),
her ders beş adım: **Oku · İzle · Değerlendirme · Görev · Üret ve Paylaş**.
